## はじめに

Ask AI Plugin は、calibre ライブラリの本について複数の AI に質問できます（OpenAI、Anthropic、Gemini、SpaceXSI、DeepSeek、Kimi、Nvidia、Perplexity、OpenRouter、Ollama など）。

できること：
- 選んだ 1 冊または複数の本について質問する
- プラグイン内で EPUB を読み（EPUB リーダー）、選んだ文字について質問する
- 自然な言葉でライブラリ全体を検索する（AI 検索）
- 2 つの AI の回答を並べて比べる
- 会話を PDF に書き出す

多くのクラウド AI には API キーが必要です。Nvidia の無料経路は、インストール後すぐに使えます。

注：このプラグインは Ask Grok から改名しました。Grok 以外にも対応しているためです。

## API キーが必要な理由

ChatGPT Plus や Gemini のサブスクリプションは、このプラグインではそのまま使えません。

AI 各社のサービスは次の 2 種類に分かれています：
- 個人向けサブスクリプション：各社のサイトやアプリ用
- API キー：開発者やこのプラグインのようなツール用

課金は別です。ChatGPT Plus の契約はここでは使えません。

有料である必要はありません。下に無料の選択肢があります。

## 無料の API キー

**既定：Nvidia AI Free（設定不要）**
- 料金：無料
- 設定：不要。インストール後すぐに使えます
- 既定モデル：`nvidia/nemotron-3.5-lightning-30b-a3b`（小さく速いモデル。設定で変更できます）
- 制限：共有の無料枠。混雑時は不安定になることがあります
- 注：プラグイン開発者が維持している無料サービスです。安定性や上限を上げたい場合は、下の選択肢を使ってください。
- 注：送信内容は、プラグインの安定性や稼働状況の分析に使われることがあります。慎重に使ってください。プライバシーを重視するなら、この無料サービスは使わないでください。開発者は利用者のプライバシーを販売したり、利益のために使ったりしません。Nvidia が無料枠をデータ分析に使うこともあります。

選択肢 1：Nvidia（安定性を重視）
- 料金：新規アカウントに無料クレジット（レート制限あり）
- プラグインの既定モデル：`nvidia/nemotron-3-nano-30b-a3b`
- 制限：おおよそ毎分 40 リクエスト（Nvidia のプランによる）
- 設定：https://build.nvidia.com/ を開いて登録
- API キーを取得し、プラグインの Nvidia AI 設定に貼り付け

選択肢 2：OpenRouter
- 無料モデル：https://openrouter.ai/models?q=free
- キーの取得：https://openrouter.ai/settings/keys

選択肢 3：Ollama（ローカル、インターネット不要）
- 料金：ずっと無料
- プライバシー：自分のコンピュータで動き、内容は送信されません
- 設定：https://ollama.com/ からダウンロードしてインストール
- ターミナルで実行：ollama pull llama3.2
- プラグインで Ollama を選ぶ。API キーは不要

## インストール

方法 1（推奨）：
1. calibre を開く
2. 環境設定 -> プラグイン -> 新しいプラグインを取得
3. “Ask AI” を検索（作者：Sheldon）
4. インストールをクリック
5. calibre を再起動

方法 2（手動）：
1. https://www.mobileread.com/forums/showthread.php?p=4547077 からダウンロード
2. 環境設定 -> プラグイン -> ファイルからプラグインを読み込む
3. .zip ファイルを選ぶ
4. calibre を再起動

## 最初の AI 設定

1. Ask AI Plugin メニューから**設定**を開く
2. **AI を追加**をクリック
3. プロバイダを選び、API キーを入力し、モデルを読み込んで選択
4. **追加**をクリック
5. **既定の AI** にするか聞かれたら、**はい**か**いいえ**を選ぶ
   - はい：以後の質問はこの AI を既定にする
   - いいえ：今の既定を維持する（例：Nvidia Free）

後から設定の**既定の AI**でいつでも変更できます。

### 設定済み AI の管理

**設定済み AI の管理**で、追加済みの AI を編集、削除、確認できます。一覧の行をダブルクリックすると開きます。

## 使い方

1. calibre で 1 冊または複数の本を選ぶ
2. 質問ウィンドウを開く：
   - ツールバーの Ask AI Plugin をクリック、または
   - グローバルショートカットを使う（既定は Ctrl+K）
3. 質問を入力
4. 送信をクリック（または Ctrl+Enter / Mac では Cmd+Enter）

書籍情報は自動で付きます。書名や著者を打ち直す必要はありません。

### 調べものに Perplexity（Sonar）を使う

出典付きの回答が欲しいときは Perplexity が向いています。

引用や検索結果が返ると、プラグインは回答の末尾に “Citations” / “Search Results” をプレーンテキストで付け、完全な URL も入れます。コピーして使えます。

## EPUB リーダー（新）

- Ask AI は、ウィンドウを開いて EPUB を直接読めるようになり、読みながら質問することもできます。
- calibre 公式との違い：AI は Ask AI プラグインにすでに設定した内容を使います。操作全体は、より現代的な形にしています。
- なぜこうするのか。公式リーダーの AI 操作は使いにくく、Viewer の行間設定は複雑です。変えるには GitHub のオープンソースとして進める必要があり、手間がかかります。
- Ask AI に内蔵した EPUB リーダー（Read & Ask とも呼びます）は、最小の形で基本だけを満たします。読書中に文字を選んですぐ AI に質問できます。プロンプトの設定と、基本的な説明もあります。

## AI 検索

AI 検索は、本を先に選ばなくても、自然な言葉でライブラリ全体を検索できます。

### AI 検索の使い方

**AI 検索を開く**：
- プラグインメニューの “AI 検索”、または
- ショートカット Ctrl+Shift+L、または
- 本を選ばずに質問ウィンドウを開く

**ライブラリへの質問例**：
- “Python プログラミングの本はありますか？”
- “Isaac Asimov の本を見せて”
- “機械学習の本を探して”
- “SF の本は何がありますか？”

**回答から本を開く**

AI は書誌情報から本を勧めます。回答中の書名をクリックすると開けます。

**ライブラリ索引の更新**（推奨）：
- 設定 -> 検索 を開く
- “ライブラリデータを更新” をクリックし、ライブラリ内の**すべての本**の書名と著者を索引する
- 本を追加または削除したら、もう一度実行する

### 機能

- **自然な言葉**：特別な記法は不要
- **ライブラリ全体**：calibre ライブラリ全体を索引して検索（簡潔な情報：ID、書名、著者）
- **意味での一致**：文脈から関連する本を見つけられる
- **クリックで開く**：結果の書名をクリックして直接開く
- **多数選択時の案内**：50 冊を超えて選ぶと、長い書誌をプロンプトに詰めず、AI 検索への切り替えを提案する

### AI 検索のヒント

- 探しているものを具体的に書く
- ジャンル、著者、主題、書誌のどれでも聞ける
- 書誌が整っているほど結果は良くなる
- ライブラリ全体から探すときは AI 検索を使う。何千冊も手で選ばない
- 数冊を深く比べるときは、およそ 30 冊まで選ぶ

## ショートカット

ショートカットは calibre で自由に変更できます。

変更方法：
1. calibre を開く
2. 環境設定 -> ショートカット
3. “Ask AI” を検索
4. 必要なショートカットを編集

よく使うショートカット（既定）：
- Ask AI：質問（グローバル）：Ctrl+K
- Ask AI：EPUB リーダー（読んで質問）：Ctrl+Shift+V（macOS は Cmd+Shift+V）
- Ask AI：設定を開く：F2
- Ask AI：AI 検索：Ctrl+Shift+L
- Ask AI：送信（ダイアログ内）：Ctrl+Enter（macOS は Cmd+Enter）
- Ask AI：ランダムな質問（ダイアログ内）：Ctrl+Shift+R（macOS は Cmd+Shift+R）

calibre で変更している場合は、その設定が優先されます。

## ランダムな質問

1. ランダムな質問をクリック（または Ctrl+Shift+R / Cmd+Shift+R）
2. AI が質問を提案します

プロンプトは 設定 -> プロンプト -> ランダムな質問のプロンプト で変更します。

## プロンプト

プロンプトのページは、ツールバーメニューまたは設定から開けます。AI に送る内容を調整します。

### ペルソナ

研究の背景と目的を書きます。この文章は、AI に送るプロンプトの先頭に付きます。

例：
- “文学の教員として、語りの技法と作品分析に注目しています。”
- “19 世紀ヨーロッパ史、特に政治運動を調べています。”
- “学生なので、初心者向けの簡単な説明が欲しいです。”

具体的であるほど、回答は目的に近づきます。

ヒント：
- 分野や職業を書く
- 習熟度（初心者、詳しい、など）を書く
- 特に知りたい点を書く

### プロンプトテンプレート

カスタムできるテンプレートは 3 つです：

1. **1 冊用プロンプト**：1 冊について質問するとき
   - 使える変数：{title}、{author}、{publisher}、{pubyear}、{language}、{series}、{query}

2. **複数冊用プロンプト**：選んだ複数の本について質問するとき
   - 使える変数：{books_metadata}、{query}

3. **ランダムな質問用プロンプト**：ランダムな質問を作るとき
   - 使える変数：{title}、{author}、{language}

### インターフェースの言語を使う

有効にすると、現在のプラグイン言語で答えるよう指示を追加します。本の言語ではなく、画面の言語で答えてほしいときに使います。

### 読んで質問

読んで質問には、このページに専用のプロンプト設定があります。

### 既定に戻す

“プロンプトを既定に戻す” で、プロンプトと関連設定を元に戻します。

## その他の機能

- 並列比較：設定で並列 AI パネルを 2 にすると、異なる AI の回答を並べて比べられる
- 履歴：会話は自動保存。履歴から過去の質問と回答を見られる
- PDF 書き出し：PDF 書き出しで会話を保存。既定のフォルダは 設定 -> 書き出し設定

## 設定

一般：
- 言語の変更
- ウィンドウサイズ
- 並列 AI パネル：2 にすると並べて比較
- リクエストのタイムアウト：AI の回答を待つ時間（既定 120 秒）
- プロンプト長のカスタム：任意の詳細設定（次の節）

AI プロバイダ：
- **AI を追加** / **設定済み AI の管理**：プロバイダの追加と編集
- **既定の AI**：質問で既定にする AI
- 追加した直後に既定にできる
- 各プロバイダ：API キー、Base URL、モデル、ストリーミング
- Kimi：キーに合わせてインターナショナルか中国本土を選ぶ

検索タブ：
- AI 検索の説明、プライバシーの注意、**ライブラリデータを更新**（ライブラリ全体の索引）

プロンプトのタブ（管理しやすいよう独立）：
- ペルソナ：研究の背景と目的を書き、回答を目的に近づける
- 1 冊、複数冊、ランダムな質問のプロンプトをカスタム
- インターフェースの言語を使う：プラグインの言語で答えさせる

書き出し設定：
- PDF の既定の保存先

## プロンプト長のカスタム

プラグインは、1 回のリクエストで AI に送る文字量を制限します。プロンプトが長くなりすぎてタイムアウトしたり、分かりにくいエラーになるのを避けます。

### 既定の上限（多くの人は変更不要）

上限に達した場合や、ローカルモデルのコンテキストが大きい場合以外は、変更しなくて構いません。

| モード | 既定の上限 |
|------|----------------|
| 1 冊 | 128,000 文字 |
| 複数冊（選択した本） | 256,000 文字 |
| AI 検索（ライブラリ全体の索引） | 簡潔な形式。検索タブを参照 |

プロンプトが長すぎるときは、現在の長さ、上限、選択した冊数を示し、ライブラリ全体の質問は **AI 検索** を使うよう案内します。

### カスタム上限を使うとき

モデルがより大きいコンテキストに対応していると分かっているときだけ有効にします。例：**Ollama** でモデル側の `num_ctx` を 128k にしている場合。

「収めるため」に何千冊も手で選び、上限を上げないでください。**AI 検索** を使います。カスタム上限は詳細向けの予備であり、大きなライブラリを検索する主な方法ではありません。

### 有効にする手順

1. 設定 -> **一般** を開く
2. **プロンプト長のカスタム上限** をオン
3. **最大プロンプト長**を文字数で入力（目安：524288）
4. **保存**をクリック

目安：1 token はおよそ 3～4 文字。Ollama ではモデル設定の `num_ctx` も合わせてください。

### 複数冊のときの動作

- **30 冊まで**：詳しい書誌（書名、著者、出版社など）で比較
- **30 冊を超える**：1 冊 1 行の簡潔な書誌
- **50 冊を超える**：質問側が **AI 検索** への切り替えを提案

## トラブルシューティング

質問が長すぎる / プロンプトが長すぎる：
- ライブラリ全体の質問：**AI 検索**（本を選ばない）、または 50 冊以上を選んだときの切り替えを受け入れる
- 複数冊の比較：30 冊までは詳しい書誌。それ以上は自動で簡潔な形式
- 非常に大きなライブラリでは、索引が上限で切れることがあります。必要なら一般設定で**プロンプト長のカスタム上限**を有効にします（目安：524288）
- エラーメッセージを読む：現在の長さ、上限、対処が書いてあります

リクエスト失敗：
- ネットワークを確認
- API キーが正しいか確認
- 別の AI プロバイダを試す

API キーが無効：
- キー全体をコピーし、空白を入れない
- 期限切れでないか確認
- SpaceXSI：console.x.ai のキーを使う。x.com ではない
- Kimi：プラットフォームをキーに合わせる（インターナショナルか中国本土）

Ollama が動かない：
- Ollama がインストールされ、起動しているか確認
- モデルを取得：ollama pull llama3.2
- モデル一覧：ollama list
- サービス：ollama serve

## プライバシー

AI に送られるもの：
- 書誌（書名、著者、出版社、日付、言語）
- 質問
- ペルソナ（有効な場合）
- カスタムしたプロンプト

送られないもの：
- calibre のタグ、コメント、レビュー
- 読書の進捗
- 個人データ

API キーの保存：
- 自分のコンピュータに保存
- 第三者には送られない
- 場所：calibre の設定フォルダ/plugins/ask_ai_plugin.json

プライバシーを優先するなら Ollama を使います（ローカルで動き、内容は送信されません）。

## ヒント

1. 最初に「この本は学習データに含まれていますか？」と聞く。含まれていないと言われた場合、助けられる範囲は限られます。
2. 並列パネルで異なる AI を比べる。
3. 質問を具体的にすると、回答も具体的になりやすい。
4. ペルソナを詳しく書くと、回答が目的に近づく。
5. 出典が必要な調べものは Perplexity。
6. ライブラリの本を探すときは AI 検索を使い、一冊ずつ探さない。
7. “質問が長すぎます” と出たら、AI 検索に切り替える、簡潔モード（30 冊超）を使う、または非常に大きなライブラリではカスタム上限を上げる。
8. 新しい AI を追加したあと、次回の質問で使うなら既定にする。
