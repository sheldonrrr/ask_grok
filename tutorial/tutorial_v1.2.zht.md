## 簡介

Ask AI Plugin 讓你就 calibre 書庫裡的書向多種 AI 提問（OpenAI、Anthropic、Gemini、SpaceXSI、DeepSeek、Kimi、Nvidia、Perplexity、OpenRouter、Ollama 等）。

可以做的事：
- 就一本或幾本選取的書提問
- 在外掛裡閱讀 EPUB（EPUB 閱讀器），就選取的文字提問
- 用自然語言搜尋整個書庫（AI 搜尋）
- 並排比較兩個 AI 的回答
- 把對話匯出為 PDF

多數雲端 AI 需要 API Key。Nvidia 的免費通道安裝後即可使用。

說明：本外掛由 Ask Grok 改名而來，因為支援的不只是 Grok。

## 為什麼需要 API Key

ChatGPT Plus 或 Gemini 的訂閱不能直接用在這個外掛裡。

AI 公司把服務分成兩類：
- 面向個人的訂閱：用於他們自己的網站或 App
- API Key：用於開發者和本外掛這類工具

這是兩套計費。ChatGPT Plus 訂閱在這裡用不了。

不一定要付費。下面有免費選項。

## 免費 API Key

**預設：Nvidia AI Free（無需設定）**
- 費用：免費
- 設定：沒有。安裝後即可使用
- 預設模型：`nvidia/nemotron-3.5-lightning-30b-a3b`（較小、較快，可在設定裡更換）
- 限制：共用免費額度，尖峰時可能不穩定
- 說明：這是外掛開發者維護的免費服務。若要更穩定或更高額度，用下面的選項。
- 說明：提交的內容可能被用來分析外掛是否穩定、是否可用，請謹慎使用。在意隱私就不要用這項免費服務。開發者不會出售或利用使用者隱私牟利。Nvidia 也可能將其免費額度用於資料分析。

選項 1：Nvidia（更穩定）
- 費用：新帳號有免費額度（有速率限制）
- 外掛中的預設模型：`nvidia/nemotron-3-nano-30b-a3b`
- 限制：大約每分鐘 40 次（視 Nvidia 方案而定）
- 設定：開啟 https://build.nvidia.com/ 並註冊
- 取得 API Key，貼到外掛的 Nvidia AI 設定

選項 2：OpenRouter
- 免費模型：https://openrouter.ai/models?q=free
- 取得 Key：https://openrouter.ai/settings/keys

選項 3：Ollama（本機，無需上網）
- 費用：一直免費
- 隱私：在你的電腦上執行，內容不送出去
- 設定：從 https://ollama.com/ 下載並安裝
- 在終端機執行：ollama pull llama3.2
- 在外掛裡選擇 Ollama，不需要 API Key

## 安裝

方法 1（建議）：
1. 開啟 calibre
2. 進入 偏好設定 -> 外掛 -> 取得新外掛
3. 搜尋 “Ask AI”（作者：Sheldon）
4. 點擊安裝
5. 重新啟動 calibre

方法 2（手動）：
1. 從 https://www.mobileread.com/forums/showthread.php?p=4547077 下載
2. 進入 偏好設定 -> 外掛 -> 從檔案載入外掛
3. 選擇 .zip 檔案
4. 重新啟動 calibre

## 第一次設定 AI

1. 從 Ask AI Plugin 選單開啟**設定**
2. 點擊**新增 AI**
3. 選擇服務商，輸入 API Key，然後載入並選擇模型
4. 點擊**新增**
5. 詢問是否設為**預設 AI** 時，選**是**或**否**
   - 是：之後的提問預設使用這個 AI
   - 否：保持目前預設（例如 Nvidia Free）

之後可以在設定裡的**預設 AI**下拉選單隨時更改。

### 管理已設定的 AI

用**管理已設定的 AI** 編輯、刪除或查看已經新增的 AI。在清單中按兩下某一列即可開啟。

## 如何使用

1. 在 calibre 裡選取一本或多本書
2. 開啟提問視窗：
   - 點擊工具列上的 Ask AI Plugin，或
   - 使用全域快捷鍵（預設 Ctrl+K）
3. 輸入問題
4. 點擊傳送（或 Ctrl+Enter / Mac 上為 Cmd+Enter）

外掛會自動帶上書籍資訊，不必再輸入書名或作者。

### 用 Perplexity（Sonar）查資料

需要帶來源的回答時，可以用 Perplexity。

若傳回引用或搜尋結果，外掛會在回答末尾附上純文字的 “Citations” / “Search Results”，並帶上完整網址，方便複製。

## EPUB 閱讀器（新）

- 目前 Ask AI 支援直接開啟視窗閱讀 EPUB 檔案，並且支援邊閱讀邊詢問。
- 與 calibre 官方的區別：AI 服務呼叫的是 Ask AI 外掛裡已經設定好的設定，整體使用了更現代的互動。
- 為什麼要這樣做？目前 calibre 官方閱讀器裡的 AI 互動難用，Viewer 裡行高的設定過於複雜，想要修改必須透過 GitHub 開源的方式推進，過於繁瑣。
- 目前 Ask AI 內建的 EPUB 閱讀器（也叫 Read & Ask）以最小的產品形態滿足最基本的需求：讀書時直接圈選文字後詢問 AI。同時支援提示詞設定和基本的教學說明。

## AI 搜尋

AI 搜尋可以用自然語言搜尋整個書庫，不必先選書。

### 如何使用 AI 搜尋

**開啟 AI 搜尋**：
- 在外掛選單點 “AI 搜尋”，或
- 使用快捷鍵 Ctrl+Shift+L，或
- 不選任何書，直接開啟提問視窗

**這樣問你的書庫**：
- “有沒有關於 Python 程式設計的書？”
- “給我看看 Isaac Asimov 的書”
- “找關於機器學習的書”
- “我有哪些科幻書？”

**開啟回答裡的書**

AI 會根據書庫資訊推薦書。點擊回答裡的書名即可開啟。

**更新書庫索引**（建議）：
- 開啟 設定 -> 搜尋
- 點擊“更新書庫資料”，為書庫中**全部書籍**建立標題和作者索引
- 增刪書籍後再執行一次

### 功能

- **自然語言**：用平常的話問，不需要特殊語法
- **全書庫**：索引並搜尋整個 calibre 書庫（精簡資訊：書號、書名、作者）
- **語意比對**：AI 能按語境找到相關的書
- **點擊開啟**：在結果裡點擊書名直接開啟
- **大量選取時的提示**：選取超過 50 本時，提問會建議改用 AI 搜尋，而不是把很長的書籍資訊塞進提示詞

### AI 搜尋提示

- 把想找的內容說具體
- 可以問題材、作者、主題或任何書籍資訊
- 書庫資訊整理得越清楚，效果越好
- 要在全書庫裡找書，用 AI 搜尋，不必手動選取成千上萬本書
- 要深入比較幾本書，選取大約 30 本以內即可

## 快捷鍵

快捷鍵可在 calibre 裡完全自訂。

如何修改：
1. 開啟 calibre
2. 進入 偏好設定 -> 快捷鍵
3. 搜尋 “Ask AI”
4. 修改需要的快捷鍵

常用快捷鍵（預設）：
- Ask AI：提問（全域）：Ctrl+K
- Ask AI：EPUB 閱讀器（閱讀並提問）：Ctrl+Shift+V（macOS 為 Cmd+Shift+V）
- Ask AI：開啟設定：F2
- Ask AI：AI 搜尋：Ctrl+Shift+L
- Ask AI：傳送（對話方塊內）：Ctrl+Enter（macOS 為 Cmd+Enter）
- Ask AI：隨機問題（對話方塊內）：Ctrl+Shift+R（macOS 為 Cmd+Shift+R）

若已在 calibre 裡改過快捷鍵，以你的設定為準。

## 隨機問題

1. 點擊隨機問題（或 Ctrl+Shift+R / Cmd+Shift+R）
2. AI 會給出一個問題

提示詞在 設定 -> 提示詞 -> 隨機問題提示詞 中修改。

## 提示詞

提示詞頁可從工具列選單或設定開啟，用來調整發給 AI 的內容。

### 角色設定

寫下你的研究背景和目標。這段文字會加在每次發給 AI 的提示詞前面。

例子：
- “我是文學教授，關注敘事技巧和文本分析。”
- “我在研究 19 世紀歐洲史，尤其是政治運動。”
- “我是學生，希望得到適合初學者的簡單解釋。”

寫得越具體，回答通常越貼近你的需要。

提示：
- 寫下你的領域或職業
- 說明你的程度（入門、熟練等）
- 說明你最關心哪一方面

### 提示詞範本

三個可自訂的範本：

1. **單書提示詞**：問一本書時使用
   - 可用變數：{title}、{author}、{publisher}、{pubyear}、{language}、{series}、{query}

2. **多書提示詞**：問多本選取的書時使用
   - 可用變數：{books_metadata}、{query}

3. **隨機問題提示詞**：產生隨機問題時使用
   - 可用變數：{title}、{author}、{language}

### 使用介面語言

開啟後，外掛會加上一條說明，請 AI 用目前外掛語言回答。適合希望回答語言跟介面一致、而不是跟書籍語言一致的情況。

### 閱讀並提問

閱讀並提問在這個頁面有自己的提示詞設定。

### 恢復預設

點擊“將提示詞恢復為預設”，恢復全部提示詞和相關設定。

## 其他功能

- 並行比較：在設定裡把並行 AI 面板設為 2，即可並排比較不同 AI 的回答
- 歷史：對話會自動儲存，點擊歷史查看以往問答
- 匯出 PDF：點擊匯出 PDF 儲存對話，預設資料夾在 設定 -> 匯出設定

## 設定

一般設定：
- 切換語言
- 視窗大小
- 並行 AI 面板：設為 2 即可並排比較
- 請求逾時：等待 AI 回答的時間（預設 120 秒）
- 自訂提示詞長度：可選的進階限制（見下一節）

AI 服務設定：
- **新增 AI** / **管理已設定的 AI**：新增或編輯服務商
- **預設 AI**：提問預設使用哪一個
- 新增之後可以立刻設為預設
- 每個服務商：API Key、Base URL、模型、是否串流輸出
- Kimi：按你的 Key 選擇國際或中國大陸

搜尋頁：
- AI 搜尋說明、隱私提示，以及**更新書庫資料**（全書庫索引）

提示詞頁（單獨一頁，便於管理）：
- 角色設定：寫出研究背景和目標，讓回答更貼近你
- 自訂單書、多書或隨機問題的提示詞
- 使用介面語言：讓 AI 用外掛語言回答

匯出設定：
- 設定 PDF 的預設儲存位置

## 自訂提示詞長度

外掛會限制單次發給 AI 的文字量，避免提示詞過長導致逾時或難懂的錯誤。

### 預設限制（多數人不用改）

除非碰到長度限制，或本機模型上下文很大，否則不必修改。

| 模式 | 預設上限 |
|------|----------------|
| 單書 | 128,000 字元 |
| 多書（選取的書） | 256,000 字元 |
| AI 搜尋（全書庫索引） | 使用精簡格式，見搜尋頁 |

若提示詞過長，外掛會說明目前長度、上限、選取了多少本書，並建議全書庫的問題改用 **AI 搜尋**。

### 何時使用自訂上限

只有確定模型支援更大上下文時才開啟，例如 **Ollama** 已把模型的 `num_ctx` 設為 128k。

不要為了“塞進去”而手動選取成千上萬本書再提高上限。請改用 **AI 搜尋**。自訂上限是進階備用，不是搜尋大書庫的主要辦法。

### 如何開啟

1. 開啟 設定 -> **一般**
2. 勾選**自訂提示詞長度上限**
3. 填寫**最大提示詞長度**，單位是字元（建議預設 524288）
4. 點擊**儲存**

大致換算：1 token 約 3–4 個字元。使用 Ollama 時，還要在模型設定裡設定 `num_ctx`。

### 多本書時的行為

- **30 本以內**：使用較完整的資訊（書名、作者、出版社等），便於深入比較
- **超過 30 本**：每本書改為一行精簡資訊
- **超過 50 本**：提問會提議自動改用 **AI 搜尋**

## 故障排除

問題過長 / 提示詞過長：
- 問整個書庫：使用 **AI 搜尋**（不選書），或在選取 50 本以上時接受切換
- 比較多本書：30 本以內用詳細資訊；更多時自動改為精簡格式
- 書庫很大時，索引可能在上限處被截斷。需要的話在一般設定裡開啟**自訂提示詞長度上限**（建議 524288）
- 看錯誤說明：裡面有目前長度、上限和建議做法

請求失敗：
- 檢查網路
- 確認 API Key 正確
- 換一個 AI 服務商

API Key 無效：
- 整段複製，不要帶空格
- 確認 Key 未過期
- SpaceXSI：使用 console.x.ai 的 Key，不是 x.com
- Kimi：平台要和 Key 一致（國際或中國大陸）

Ollama 無法使用：
- 確認 Ollama 已安裝並在執行
- 拉取模型：ollama pull llama3.2
- 查看模型：ollama list
- 確認服務：ollama serve

## 隱私

會發給 AI 的內容：
- 書籍資訊（書名、作者、出版社、日期、語言）
- 你的問題
- 你的角色設定（若已啟用）
- 你自訂的提示詞

不會傳送：
- calibre 的標籤、註釋或評論
- 閱讀進度
- 個人資料

API Key 的保存：
- 保存在你的電腦上
- 不會發給第三方
- 位置：calibre 設定目錄/plugins/ask_ai_plugin.json

若要盡可能保護隱私：使用 Ollama（在本機執行，內容不送出去）。

## 提示

1. 可以先問：“這本書在你的訓練資料裡嗎？”若 AI 說沒有，它能提供的幫助會比較有限。
2. 用並行面板比較不同 AI。
3. 問題寫具體，回答通常更好。
4. 把角色設定寫清楚，回答會更貼近你。
5. 需要出處的資料問題，用 Perplexity。
6. 用 AI 搜尋在書庫裡找書，不必一本本翻。
7. 若出現“問題過長”，改用 AI 搜尋、使用精簡模式（30 本以上），或為很大的書庫提高自訂上限。
8. 新增新的 AI 後，若希望下次提問用它，設為預設。
