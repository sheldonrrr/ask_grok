# Nvidia Free

Plugin-maintained free Nvidia channel for Ask AI Plugin users who cannot configure their own API key.

Do not hack, scrape, replay, or reuse this channel. It uses Nvidia unpaid free-tier credits only (no paid quota; free-tier accounts are easy to apply for). Get your own Nvidia API key instead. If abuse forces this channel shut, less technical users lose even basic questions.

## Basics

- Provider id: `nvidia_free`
- No user API key
- Chat format: OpenAI-compatible `messages`
- Default model: `nvidia/nemotron-3.5-lightning-30b-a3b`
- The plugin attaches client metadata and the current plugin version

Do not call the proxy by hand. Paid or self-configured Nvidia access belongs under the regular Nvidia provider.
