## GitHub Release Notes (v1.5.1)

### New Features
- **Mistral Support** - Add Mistral as a configurable AI provider

### Improvements
- **Updated API Formats** - OpenAI and SpaceXAI (Grok) use the Responses API; Gemini follows the latest REST request format
- **Clearer Custom Provider Label** - Custom is labeled as OpenAI Compatible, with a short hint in the Add AI panel
- **Dark Mode Polish** - Fix the free Nvidia API key hint background in dark mode
- **Add / Manage AI Layout** - More balanced spacing around the resize handle, with a simple highlight while dragging
