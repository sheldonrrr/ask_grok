## GitHub Release Notes (v1.6.0)

### New Features
- **Web Search in Ask** - Turn on Web Search in the Ask toolbar to look up live web results while you ask. AI can search again or write a summary in the same answer
- **Brave Search API Key** - Bind your own Brave Search API key in Configuration → Search. The plugin does not ship a shared key
