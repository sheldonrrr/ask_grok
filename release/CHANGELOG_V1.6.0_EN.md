## GitHub Release Notes (v1.6.0)

### Improvements
- **Default Free Model** - Switched the Nvidia Free default to a smaller, more reliable model; the previous default was less stable and often unavailable
- **Reply Readability** - Fixed hard-to-read text in AI replies (including quotes) so answers stay clear in both light and dark themes
- **Simple Goal Recommendation** - About now recommends [Simple Goal for calibre](https://www.mobileread.com/forums/showthread.php?p=4602877), a plugin for setting reading goals and tracking live reading progress. Visit the page to install and try it
