## GitHub Release Notes (v1.6.3)

### Changes
- **Longer default request timeout** - New installs now wait 120 seconds for an AI reply (was 60), which gives slower free models more time to respond. If you were still on the old 60-second default, it is updated to 120 automatically. A timeout you set yourself is left unchanged.
