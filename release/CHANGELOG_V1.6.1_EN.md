## GitHub Release Notes (v1.6.1)

### Fixes
- **Nvidia Free Default Model** - Switched the built-in free channel to a model that still works on Nvidia's Free Tier. If you were still using the previous default, it is updated automatically. You can pick another model in settings, or use your own Nvidia API Key for more stable access
